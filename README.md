I'm Sasha — a full-stack software engineer based in Germany who enjoys building, improving, and occasionally overengineering things that probably worked fine already.

My primary focus is Android development, where I design and develop both business applications and side projects driven by curiosity, interest, and, most importantly, the fun of creating something new.

📖 Currently, I’m diving into Jetpack Compose <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/jetpackcompose/jetpackcompose-original.svg" height="11" alt="jetpack compose" />, the modern toolkit for building responsive Android UIs. I still work extensively with traditional Views as well — partly for compatibility, partly because legacy code never sleeps.

🔧 Besides the frustrating life of a software engineer, I also enjoy working on cars and modifying them — both visually and mechanically.</br>
